# Kings and Pigs — 游戏设计规范

**日期：** 2026-06-05  
**引擎：** Godot 4.6  
**平台：** PC Windows  
**类型：** 2D 横版 Metroidvania（跑跳 + 战斗 + 技能解锁探索）  
**素材包：** [Kings and Pigs](https://pixelfrog-assets.itch.io/kings-and-pigs)

---

## 一、整体架构

### 项目结构

```
kings-and-pigs/
├── scenes/
│   ├── world/          # 大地图各区域房间场景
│   ├── player/         # 玩家节点场景
│   ├── enemies/        # 各类敌人场景
│   ├── ui/             # HUD、菜单、存档界面
│   └── managers/       # GameManager、SaveManager
├── scripts/
├── assets/
│   ├── sprites/        # Kings and Pigs 素材
│   ├── audio/
│   └── fonts/
└── resources/          # Resource 文件（技能定义、敌人数据）
```

### 核心单例

| 单例 | 职责 |
|------|------|
| `GameManager` | 游戏状态机、场景切换、全局事件总线 |
| `SaveManager` | 存档读写（`user://save.json`） |

### 技术要点

- 玩家使用**状态机**驱动，每个状态为独立类
- 敌人继承 `EnemyBase` 基类，各类型覆写行为方法
- 房间切换通过 `RoomTransition` 节点触发，黑色淡入淡出过渡
- 技能数据以 `SkillResource`（`Resource` 子类）定义，便于扩展

## 二、世界与关卡

### 地图结构

4 个区域，每区域 6-8 个房间，房间为独立 Scene，通过 `RoomTransition` 节点连接。

| # | 区域 | 主题 | 解锁条件 |
|---|------|------|----------|
| 1 | 王国庭院 | 教学区，开放 | 初始区域 |
| 2 | 猪兵营地 | 敌人密集，战斗为主 | 击败庭院 Boss + 拥有「翻滚」技能 |
| 3 | 地下猪窟 | 黑暗环境，跳台为主 | 击败营地 Boss + 拥有「二段跳」技能 |
| 4 | 猪王城堡 | 最终区域，综合挑战 | 击败地下 Boss + 拥有「冲击波」技能 |

### 房间系统

- 每个房间为独立 Scene，通过 `RoomTransition` 区域节点触发切换
- 玩家位置在切换时保持空间连续
- 已探索房间 ID 记录在存档中（用于地图着色显示）

### 存档点

每个区域设 2 个存档点（王座/壁炉交互对象），触碰自动存档并回满血量。

## 三、玩家与战斗系统

### 玩家属性

| 属性 | 数值 |
|------|------|
| 生命值 | 6 格（心形图标） |
| 耐力槽 | 100 点，翻滚消耗 25，自动恢复 |
| 移动速度 | 200 px/s（可调） |
| 跳跃高度 | 300 px（初速度） |

### 操作映射

| 按键 | 行为 |
|------|------|
| A / D 或 ←/→ | 左右移动 |
| Space | 跳跃 |
| J | 攻击（最多三连击） |
| K | 格挡（正面伤害减免 80%） |
| L | 翻滚（0.4s 无敌帧，消耗耐力 25） |
| Shift + J | 释放当前装备技能 |
| Esc | 暂停菜单 |

### 玩家状态机

```
Idle ─┬─→ Run ──→ Jump ──→ Fall
      ├─→ Attack ──→ AttackCombo2 ──→ AttackCombo3
      ├─→ Roll（无敌帧 0.4s）
      ├─→ Block
      ├─→ Hurt
      └─→ Dead
```

### 技能系统

4 个主动技能，通过击败 Boss 或探索收集解锁：

| 技能 | 解锁时机 | 效果 |
|------|----------|------|
| 翻滚强化 | 击败区域 1 Boss | 翻滚距离 +50%，无敌帧延长至 0.6s |
| 二段跳 | 击败区域 2 Boss | 空中可再跳一次 |
| 冲击波斩 | 击败区域 3 Boss | 近战释放前向冲击波，可远程命中 |
| 王者之气 | 收集全部王冠碎片（隐藏收集） | 短时无敌 + 全屏震慑所有敌人 |

## 四、敌人系统

### 敌人基类 `EnemyBase`

**状态机：** `Patrol → Chase → Attack → Hurt → Dead`

- 巡逻：在设定路点间往返
- 追击：玩家进入侦测范围触发
- 攻击：进入攻击距离触发，带攻击前摇
- 区域切换后敌人重生，同一房间内击杀不重生

### 4 种基础敌人

| 敌人 | 区域 | 行为 | 攻略要点 |
|------|------|------|----------|
| 猪兵（Pig） | 1-4 | 巡逻 + 近战冲撞 | 基础敌人，直接攻击即可 |
| 盾兵猪（Box Pig） | 2-4 | 举盾防御 + 反击 | 正面有格挡，需绕后攻击 |
| 炸弹猪（Bomb Pig） | 3-4 | 投掷炸弹（弧线轨迹） | 翻滚躲避炸弹，近身击杀 |
| 国王猪（King Pig） | 各区 Boss | 三阶段战斗 | 见 Boss 设计 |

### Boss 三阶段设计（通用模板）

| 阶段 | 血量区间 | 行为 |
|------|----------|------|
| 阶段 1 | 100% - 60% | 基础攻击 + 冲锋 |
| 阶段 2 | 60% - 30% | 召唤 2 只小猪兵 + 跳砸攻击 |
| 阶段 3 | 30% - 0% | 狂暴模式：速度 +40%，攻击间隔缩短 |

## 五、存档与 UI 系统

### 存档格式（`user://save.json`）

```json
{
  "current_area": 1,
  "last_save_point": "area1_save2",
  "player_hp": 6,
  "unlocked_skills": ["roll_upgrade"],
  "defeated_bosses": ["boss_area1"],
  "explored_rooms": ["area1_room1", "area1_room2"]
}
```

### UI 界面清单

| 界面 | 内容 |
|------|------|
| 主菜单 | 新游戏 / 继续游戏（有存档时可用）/ 退出 |
| HUD | 心形血条（6 格）+ 耐力槽 + 当前技能图标 |
| 暂停菜单 | 继续 / 技能列表 / 返回主菜单 |
| 存档提示 | 淡入淡出"已存档"文字 + 血量回满动画 |
| 死亡界面 | "你已阵亡" + "从存档点重试"按钮 |

### 场景过渡

所有场景切换使用 `CanvasLayer` + `AnimationPlayer` 实现黑色淡入淡出（0.3s）。
